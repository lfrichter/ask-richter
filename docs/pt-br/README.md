## 🔄 Fluxo De Atualização

1. **Decisão / Requisito:** Pode ser discutido e concebido em português com os desenvolvedores.
2. **Registro Canônico:** O agente registra a decisão em inglês nos arquivos canônicos (`META_SPEC.md`, `AGENTS.md`, `docs/adr/`).
3. **Espelho Localizado:** A documentação em `docs/pt-br/` é sincronizada para fornecer visibilidade clara ao time em português.
